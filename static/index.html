使用说明

📚 快速上手流程

  1. 配置目录：点击右上角"设置"按钮，在"通用设置"中配置源目录（下载目录）和各分类的目标目录
  2. 配置 AI 模型：AI 是可选增强；不开启也能完成扫描、匹配、清理和转移
  3. 文件入库扫描：点击顶部"文件入库扫描"按钮，系统会按文件名、版本和分类进行智能分组
  4. 审核分组：在分组列表中查看每个文件/文档/软件包的不同版本，确认需要入库或保留的版本
  5. 执行处理：入库扫描时点击"批量入库整理"；清理计划中点击"执行清理计划"，执行前会再次确认

🎯 核心功能说明

  • 文件入库扫描：智能识别同名文件、文档或软件包的不同版本，自动分组。支持识别版本号、平台信息等
  • 生成清理计划：扫描目标目录中已有的历史版本，结合版本号、保留策略和 AI 建议生成可确认的清理方案
  • 跨格式查重：支持忽略扩展名差异的去重（如将 .dmg 与 .pkg 视为同一组文件），可在设置中开启
  • 保留策略：默认保留最新版本，也可以按分组设置"保留2版"或"永不清理"
  • 手动保留规则：点击锁图标可标记特定版本"始终保留"，下次分析时自动应用

🧹 清理计划与历史版本

  • 默认策略：每组默认保留最新版本，其余旧版本列为可清理候选
  • 保留2版：适合需要保留稳定版、回退版本或历史文档的分组
  • 永不清理：适合驱动、系统工具、签名包、合同、归档资料等需要长期留档的分组
  • 全局策略：在"设置" → "清理策略"中配置默认保留数、排除关键词和排除目录
  • AI 建议：只用于辅助判断，不会覆盖手动保留和受保护策略
  • 转移失败保护：只要本轮存在转移失败或同名跳过，系统就不会继续执行旧版删除

📁 文件分类管理

  • 文档资料：.pdf, .docx, .xlsx, .pptx, .txt, .md, .epub - 常用文档格式
  • Mac 应用：.dmg, .pkg - macOS 安装包格式
  • iOS 应用：.ipa - iOS 应用包（需越狱或签名工具安装）
  • Windows 应用：.exe, .msi - Windows 安装包格式
  • 自定义分类：在"设置"中可添加新分类，并配置是否启用"跨格式查重"开关

🚦 AI 模型状态指示灯

  • 🟢 绿色：模型连接正常，可正常使用
  • 🔴 红色：模型连接失败或未配置
  • ⚪ 灰色：尚未检查连接状态
  • 检查时机：当前选中模型每 30 秒自动刷新；打开下拉菜单时刷新全部

🔐 本地配置与安全

  • 配置位置：用户配置保存在本机 ~/.software_organizer/，不会写入项目仓库
  • 密钥处理：设置页只显示已配置状态，后端接口不会把真实 API Key 原样返回给页面
  • 文件权限：配置和规则文件采用原子写入，并限制为仅当前用户可读
  • 依赖方式：Gemini、DeepSeek、Ollama 使用 HTTP 调用，打包版不强制携带额外 AI SDK

⚡ 批量入库整理说明

  • 转移操作：将源目录中勾选的文件移动到对应分类的目标目录 (支持覆盖旧版本)
  • 清理操作：在清理计划中删除未受保护、未被勾选保留的旧版本；受保护版本不会进入删除队列
  • 安全确认：执行前会显示转移、清理、受保护跳过、未选目标和待清理文件预览，确认后才会执行
  • 安全边界：转移仅允许从已配置源目录进入已配置目标目录；清理仅允许操作已配置目标目录
  • 变体保护：语言包、补丁和不同 CPU 架构分别成组，避免将配套文件当作旧版本删除

⌨️ 小技巧

  • 使用分组头部的复选框可以"全选/取消全选"该组内所有文件
  • 点击目标路径下拉框可选择具体的子目录存放位置
  • 清理前先看"已保护"和"可清理"数量，确认没有误删历史版本
  • 手动保留规则基于文件名记忆，同一文件分组的不同版本可以分别设置
